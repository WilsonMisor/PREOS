# Architecture Economics Model

For each material architecture option record:

- decision/problem;
- current workload and maturity stage;
- cost now;
- cost at expected next stage;
- variable cost drivers;
- economic-abuse surface;
- complexity tax;
- specialist/operational burden;
- vendor dependency and concentration;
- failure cost;
- migration/switching cost;
- activation assumption;
- measurable activation trigger;
- review trigger;
- selected option and rationale.
