## Operating-system concepts explicitly retained

- Eight-engine PREOS interpretation and source extraction/provenance.
- Production risk generation dimensions, aggregation hierarchy, control dependency graph and failure-policy classification.
- Full-stack 52-domain taxonomy.
- Software economics, cost concentration, economic-abuse surface and complexity economics.
- Adaptive architecture and nondeferrable first-production controls.
- Security/attack evolution, reliability/failure engineering, resource exhaustion, data correctness/silent wrongness, financial correctness, trust/trade assurance and human/operational failure.
- Cost and complexity activation matrix for Redis, replicas, search, Kafka, Kubernetes, service mesh, microservices, sharding, multi-region, data platforms, graph DB, CQRS, event sourcing, fraud, observability, WAF/bot management, feature flags, managed queues and object storage.
- Architecture Decision Registry and Deferred Complexity Registry.
- G0-G11 production gates and hard AI authority boundary.
- Atomic check schema, stable-ID traceability and evidence minimum.
- 1,300-question readiness bank and virtual-team decision authority matrix.
- Reconciliation framework and production feedback loop.

If this ledger conflicts with the preserved original package, the original package is authoritative for source fidelity; changes require explicit migration/versioning.
