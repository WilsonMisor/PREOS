# Legacy Seven Implementation Gates to PREOS G0-G11

The abandoned gstack production-engine design grouped Stage-5 implementation assurance into seven useful lenses. Preserve them as a compatibility/implementation view only; they do not replace or renumber PREOS G0-G11.

| Legacy lens | PREOS canonical gate |
| --- | --- |
| Architecture | G2 Architecture |
| Security | G3 Security / Identity / Trust / Privacy |
| Data | G4 Data Correctness |
| Performance | G6 Performance / Capacity |
| Failure | G7 Failure / Recovery |
| Deployment | G8 Change / Deployment Safety |
| Operations | G9 Operations / Support |

PREOS additionally requires G0 Source / Project Contract, G1 Product / Business Correctness, G5 Financial Correctness / Economics, G10 Legal / Compliance / Accessibility, and G11 Evidence / Authority.

All gate states remain GREEN, AMBER, RED, HUMAN REVIEW or UNKNOWN. UNKNOWN never silently becomes GREEN.
